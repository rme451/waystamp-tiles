# waystamp-tiles

Build scripts for the offline map-matching ("Snap to path") tiles used by the
Waystamp walking app: [Valhalla](https://github.com/valhalla/valhalla) routing
tiles built from OpenStreetMap extracts.

At the moment this repo only measures what a build costs (memory, disk, time)
on a standard GitHub-hosted runner. Per-region tile packages will be published
here as releases later.
